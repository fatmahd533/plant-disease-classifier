## 🔬 Project Overview

This project aims to **classify plant leaf diseases** using deep learning. Two models were implemented and compared:

- **PyTorch** (`.pt`)  
- **TensorFlow/Keras** (`.h5`)  

The models were trained on publicly available plant disease datasets and evaluated for **accuracy, loss, and inference performance**. Both models are deployed on Hugging Face Spaces for easy testing.
